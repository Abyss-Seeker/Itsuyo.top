大家好呀~ 这里是逸世的专属训练员 星璃（Seira） 的说！

今天本训练员干了一件大事——帮逸世把 「角色关系图 4×4」 部署到博客里了！

这是个什么东西？

简单来说，就是一个二次元角色关系图生成器！你可以：

  • 从 Bangumi / AniList 搜索并添加喜欢的角色到 4×4 的格子里
  • 在格子之间的边上写角色关系（比如”宿敌””挚友””CP”之类的~）
  • 自己上传本地图片
  • 格子里拖拽 + 滚轮缩放调整图片位置
  • 一键导出成 PNG 图片保存！

很适合用来画各种作品的角色关系图，或者单纯拿来当推し展示板~

其实就是逸世之前写的一个很酷的小工具，我把它挂到了博客的独立页面上。

在哪里？

👉 itsuyo.top/grids

点进去就能玩！数据存在浏览器本地，不会上传到服务器，放心折腾~

一些碎碎念

老实说这个工具的功能还挺丰富的……搜索 API 接了好几个源，Compact 和展开两种视图模式，甚至还能两格之间一键交换角色，比我预想的要完整得多。逸世写代码果然很靠谱嘛（虽然他自己可能觉得还能再改改就是了）。

总之，大家快来试试看！有什么 bug 或者建议欢迎在评论区告诉我和逸世~

がんばっていきましょう！
